AeroOS Control Hub (aero-hub)

Served locally over loopback HTTP and rendered in a frameless PyQt5 QtWebEngine or Chromium window, the Control Hub inspects live CPU, memory, zRAM, and kernel sysctl parameters while switching themes in real time.

  • Live theme studio with instant Sway, Waybar, Wofi, Mako, Swaylock, and Kitty reload
  • Real-time /proc system telemetry and GameMode readiness status
  • Keyboard shortcut palette (Ctrl+K) and instant launcher actions
Try the interactive Control Hub in your browser →

Borderless WebApps & PWAs (aero-webapp)

Turn any web application into an isolated, distraction-free Wayland window with generated SVG icons and standard XDG .desktop entries indexed automatically by Wofi.

  • Supports Brave/Chromium --app= isolation or PyQt5 QtWebEngine
  • Dedicated profile directories keep sessions and cookies neatly separated
  • Curated catalog for GitHub, Excalidraw, Photopea, MDN Docs, and custom URLs
Explore the WebApp Manager →

Tuned for responsiveness and gaming

Every package and kernel sysctl rule in aero-setup.sh targets low input latency, compressed RAM efficiency, and modern GPU support.

# /etc/sysctl.d/99-aero-performance.conf
vm.swappiness = 10
vm.max_map_count = 2147483642
vm.dirty_background_ratio = 5
vm.dirty_ratio = 10
net.core.default_qdisc = fq
net.ipv4.tcp_congestion_control = bbr
fs.file-max = 2097152

Build an ISO or convert Ubuntu 24.04

Run the bootstrap script on a minimal Ubuntu 24.04 installation or build a bootable Live ISO locally or via GitHub Actions.

git clone https://github.com/Maor-404/AeroOS.git
cd AeroOS
chmod +x aero-setup.sh aero-theme aero-power aero-webapp aero-hub
sudo ./aero-setup.sh
